# Sound credits

Trill bundles the sounds below. Every file was converted to AAC (`.m4a`), trimmed of leading and
trailing silence, and loudness-matched; no other changes were made. Each source is CC0 / public domain,
so no attribution is legally required, but the authors are credited here anyway.

## Notification Tones (28 sounds)

- **Author:** Aarni Koskela (akx)
- **Source:** https://github.com/akx/Notifications (commit db184d3)
- **Licence:** dual-licensed by the author, "choose between": CC0 Public Domain, or CC BY 3.0. Trill
  uses these under **CC0**. The credit above also satisfies CC BY 3.0 attribution.
- **Licence verified at:** the "License" section of https://github.com/akx/Notifications/blob/master/README.md
  (https://creativecommons.org/publicdomain/mark/1.0/ and https://creativecommons.org/licenses/by/3.0/)
- **Not bundled from this repository:** the longer or harsher tones (Sharp, Reverie, Jinja,
  Belligerent, Whistleronic-Down, Chord2_Rev, Glitch, Newsflash).

## UI SFX (48 sounds)

- **Author:** Yuki Capital / Romain Simon (UI SFX), https://uisfx.com. Procedurally generated audio.
  Bundled: the `notification`, `mention`, `achievement` and `warning` (named "Alert") cues from each of
  the twelve sound packs (arcade, cinematic, dreamy, glass, mechanical, minimal, organic, rubber, scifi,
  soft, studio, zen).
- **Source:** https://github.com/romainsimon/uisfx (commit 9950fe6), `packages/uisfx/sounds/`
- **Licence:** CC0 1.0 Universal for the audio (the repository's code is MIT; no code is bundled).
- **Licence verified at:** https://github.com/romainsimon/uisfx/blob/main/LICENSE-AUDIO (and the License
  section of the repository README); copied here as `UI SFX/LICENSE-AUDIO.txt`.

## Considered and not used

- **Kenney Digital Audio / UI Audio:** CC0 per kenney.nl, but the Digital Audio archive could not be
  obtained without bypassing kenney.nl's bot block, and UI Audio is clicks and switches rather than
  notification sounds.
- **elementary OS sound theme** (https://github.com/elementary/sound-theme, `debian/copyright` on the
  `deb-packaging` branch): mixed per-file licences (CC-BY-SA, Pixabay licence, CC0). Only a single CC0 file
  was usable, so it was left out.
- **Google Material Design sounds / Assistant sound library:** the Assistant library forbids standalone
  redistribution; the Material sound page's licence could not be verified.
- **freedesktop, KDE Ocean, Pidgin, GNOME themes:** share-alike or GPL licensing; not checked further.
